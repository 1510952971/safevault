# SafeVault 极空间 NAS 私有化部署与远程同步指南

本文档专为 **极空间（Zspace）私有云/NAS 用户** 编写，指导您如何将 SafeVault 部署到极空间的 Docker 中、生成专属外网访问网址、并在手机移动端与电脑桌面端实现全自动**零知识加密多端同步**。

---

## 一、极空间 NAS 核心部署优势

- **真·零知识端到端加密**：您在手机或电脑端输入的主密码，**绝不发送给极空间服务器**。极空间 Docker 仅存储经过 AES-GCM-256 位强加密的密文数据包，即使极空间被外部攻击，数据也如同乱码天书，无法破解；
- **全生态多端覆盖**：极空间生成专属网址后，iPhone / iPad（Safari）、安卓手机（Chrome / 微信 / Edge）、Windows / Mac 桌面电脑均可实时连接并同步；
- **掉电防丢持久化**：挂载极空间本地物理存储文件夹，容器更新或 NAS 重启数据永久保留。

---

## 二、极空间 NAS Docker 部署全流程

### 步骤 1：在极空间中规划数据目录
1. 打开极空间电脑客户端或手机 App；
2. 进入 **「个人空间」**（或团队空间），新建文件夹路径：
   ```text
   /docker/safevault/data
   ```
   > 该目录用于持久化保存您的密文数据库文件，绝不丢失。

---

### 步骤 2：在极空间 Docker 中创建容器

#### 方式 A：在极空间 Docker 界面可视化创建（新手推荐）
1. 打开极空间系统内的 **「Docker」** 应用；
2. 点击 **「本地镜像」** ➔ **「添加本地镜像」**（可直接导入本工程构建好的 `safevault:latest` 镜像或从 Docker Hub 拉取）；
3. 选中镜像，点击 **「创建容器」**：
   - **容器名称**：`safevault-nas`
   - **自启动**：勾选“随 NAS 启动”（建议开启）
4. **端口映射**：
   - 容器端口：`8088`
   - 本地端口：`8088`（若 8088 被占用，可自定义为如 `18088` 等其他空闲端口）
   - 注意：自定义本地端口为 `18088` 时，容器端口仍保持 `8088`，即 `18088 → 8088`。若电脑开启代理/VPN，请将 NAS 局域网 IP 或 `192.168.0.0/16` 设为直连。
5. **文件夹路径挂载（极关键）**：
   - 本地路径（极空间路径）：选中在步骤 1 创建的 `/docker/safevault/data`
   - 容器内部路径：输入 `/app/data`
   - 权限：选择 **“读写”**
6. **环境变量**：
   - 添加 `PORT`，值为 `8088`
   - 添加 `TZ`，值为 `Asia/Shanghai`
7. 点击 **「应用」**，极空间将自动拉起容器运行。

#### 方式 B：通过 SSH 或 Compose 命令行一键拉起
如果您在极空间启用了 SSH 终端管理，可在工程根目录下执行：
```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

## 三、配置极空间「远程访问」生成专属外网网址

极空间系统自带极为便捷的远程访问与内网穿透能力，可以让您在外出、公司、出差时，手机和笔记本依然能随时同步家里的密码库：

1. 打开极空间客户端 ➔ 进入 **「系统设置」** ➔ **「远程访问」**（或应用中心中的「远程访问」）；
2. 点击 **「添加远程访问」**：
   - **名称**：`SafeVault 个人密码库`
   - **协议**：`HTTP`
   - **局域网 IP**：填入极空间内网 IP（例如 `192.168.1.100` 或本机 `127.0.0.1`）
   - **端口**：填入前面映射的本地端口 `8088`
3. 保存后，极空间将为您生成一条**安全公网远程访问网址**，例如：
   ```text
   https://zspace-remote.example.cn:port  或者 极空间官方分配二级域名
   ```
4. 复制该网址，您可以在全球任意有网络的地方通过该网址访问 SafeVault。

## 四、多端使用与数据同步指南

### 1. 移动端配置（iOS / Android 沉浸式小程序）
1. 手机打开自带浏览器（iPhone 使用 **Safari**，安卓使用 **Chrome / Edge**）；
2. 在地址栏输入上面极空间生成的网址；
3. **添加到主屏幕**：
   - **iOS**：点击 Safari 底部中间的 **“分享”** 图标 ➔ 下滑选择 **“添加到主屏幕”**；
   - **Android**：点击右上角菜单 `...` ➔ 选择 **“添加到主屏幕”** 或 **“安装应用”**；
4. 手机桌面上即刻生成 **SafeVault** 图标。点击打开后，无浏览器地址栏、全屏运行，如同原生微信小程序一样流畅；
5. 进入后点击右上角 **「云同步」** 图标，注册或登录您的极空间同步账号，手机上的密码即可与极空间实现秒级双向加密同步。

---

### 2. 电脑桌面端配置（Windows / Mac）
1. 打开桌面端应用（或浏览器访问极空间网址）；
2. 点击顶栏右侧的 **「极空间云同步」**（或在右侧防卫面板点击「极空间云同步中心」）；
3. 填入极空间网址（局域网内直接填 `http://192.168.x.x:8088`，出差在外填极空间远程网址）；
4. 输入同步账号与主密码，点击「立即登录」；
5. 系统自动校验摘要，并拉取最新密文在本地由主密码解密展现！

---

### 3. 云端账号同步与历史版本回滚

1. 所有电脑、手机都使用同一个 SafeVault 同步账号登录；密码明文不会上传，极空间只保存认证摘要和加密密文。
2. 每次设备推送都会校验云端版本号。若另一台设备已经更新，旧设备的推送会被拒绝，提示先执行「智能双向同步」，避免误覆盖。
3. 服务端把完整数据库写入独立映射目录 `safevault-backup/database/`，并把用户历史版本写入 `safevault-backup/users/`，默认各保留最近 30 份。
4. Docker 需要把极空间 `Docker/safevault-backup` 单独映射为 `/app/backup`。更新时保留 `data/` 与 `safevault-backup/`；即使误删整个 `data/`，重启也会从外部最新备份恢复。

### 4. 远程访问地址变化

- 极空间远程访问页面中的 `http://127.0.0.1:xxxxx` 是当前电脑的临时代理地址，不是 SafeVault 的固定地址；每次启动端口变化是正常的。
- 页面端会自动使用当前网页地址。客户端也会自动忽略已保存的旧本机代理端口，跟随当前页面，不需要重新注册同步账号。
- 如果登录提示代理指向了另一份数据库，请检查 `safevault` 容器的文件夹挂载：原 NAS 数据目录必须始终映射到容器 `/app/data`。不能为了更新或处理端口变化而删除容器、重新创建空数据目录。
- 如果旧的极空间远程访问链接可以登录，而新链接提示“账号已在服务器中注册”但登录失败，说明远程访问映射指向了不同服务或不同数据目录。应编辑远程访问条目，恢复到原来能登录的目标（本机 Docker 通常使用 `127.0.0.1:<宿主机端口>`），不要改用另一条 LAN 地址，也不要重新注册账号。
- 只有从普通 Windows 桌面端直接连接时，才应填写固定 HTTPS 域名或稳定远程地址；不要把某一次生成的 `127.0.0.1:xxxxx` 复制给另一台电脑。

## 五、程序版本更新与维护

SafeVault 现已全面内置 **GitHub Releases 自动更新检测**：
1. 在 SafeVault 界面顶栏点击版本号（当前为 `v1.2.6`）或在防卫面板点击 **「检查版本更新」**；
2. 系统会自动比对 GitHub 最新发布的 Release 源码包、Windows 客户端与安卓 APK；
3. **极空间 Docker 更新指引**：
   - 当 GitHub 发布新版本镜像后，进入极空间「Docker」➔「镜像库」拉取最新镜像；
   - 停用旧容器 ➔ 选择「重置/更新容器」即可；
   - **由于数据已经挂载至 `/docker/safevault/data`，更新容器绝对不会造成任何数据丢失！**
