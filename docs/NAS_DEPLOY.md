# SafeVault 密码数据库 - 极空间 NAS 私有化部署与远程多端同步完整指南

本文档专门针对 **极空间私有云（ZSpace NAS）** 打造，提供从容器部署、公网远程网址生成、多端移动/桌面应用数据同步到 GitHub 版本更新的全链路保姆级实操步骤。

---

## 🌟 核心特性与架构优势

- **零知识纯前端强加密（Zero-Knowledge）**：所有密码的加密、解密和派生均在访问者的电脑或手机**本地内存**中完成。极空间 NAS 仅负责存储高强度加密密文（AES-GCM-256），即使 NAS 管理员或内网其他人扫描数据库，也绝对无法获取任何明文密码。
- **全离线与多端兼容**：即使断网，手机和电脑端已打开的应用依然能够完全离线查看和加解密；
- **极轻量运行**：纯原生 Node.js 同步中枢服务，运行时内存占用 < 30MB，极速冷启；
- **全自动穿透生成网址**：利用极空间系统自带的远程访问功能，一键生成外网 HTTPS 专属访问网址，无需公网 IP。

## 🚀 步骤一：极空间 NAS 容器部署

为照顾不同用户的使用习惯，本项目提供 **两种极为顺滑的部署方案**：

### 方案 A：极简文件夹挂载法（强烈推荐，无需电脑安装或启动 Docker）

这是最方便、最推荐给所有极空间用户的方案，利用极空间自带的官方镜像直接拉起：

1. **准备部署文件夹**：
   - 本工程内已为您一键生成好 `deploy/zspace-package` 文件夹（包含编译好的前端静态网页 `dist/`、纯原生后端服务 `server/`、配置与持久化存储 `data/`）。
   - （*如后续修改了代码，双击根目录下的 `生成极空间部署包.bat` 即可随时重新打包*）。
2. **上传到极空间**：
   - 打开极空间电脑客户端或手机 App 的「个人空间」；
   - 在 `Docker` 目录下新建一个文件夹（例如命名为 `safevault`）；
   - 将电脑上 `deploy/zspace-package` 目录内的所有文件与文件夹，直接上传/复制到极空间的 `Docker/safevault` 目录下。
3. **在极空间 Docker 中创建容器**：
   - 打开极空间客户端中的 **「Docker」** 套件；
   - 切换到 **「镜像仓库」** 标签，在搜索框输入 `node`，找到官方 `node` 镜像，下载标签选择 `20-alpine`（体积仅几十兆）；
   - 切换到 **「本地镜像」**，在下载好的 `node:20-alpine` 右侧点击 **「创建容器」**；
   - 按如下参数配置：
     - **基本设置**：
       - 容器名称：`safevault`
       - 勾选：`开机自动启动`（或设置为容器退出时总是重启）
     - **文件夹路径映射**：
       - 点击添加路径：选择极空间中的 `Docker/safevault` 文件夹；
       - 装载路径（容器内部）：填写 `/app`
       - 权限模式：`读写`
       - 再新建极空间目录 `Docker/safevault-backup`，添加第二个路径映射到 `/app/backup`，权限设为`读写`；该目录必须位于 `safevault/data` 之外。
     - **端口设置**：
       - 本地端口（宿主机）：填写 `8088`（若 8088 已被占用，可填任意未用端口如 18088）
       - 容器端口：填写 `8088`
       - 协议：`TCP`
     - **环境设置**（环境变量）：
       - 点击添加变量：`PORT` = `8088`
       - 点击添加变量：`TZ` = `Asia/Shanghai`
       - 点击添加变量：`DATA_DIR` = `/app/data`
       - 点击添加变量：`BACKUP_DIR` = `/app/backup`
       - 点击添加变量：`STATIC_DIR` = `/app/dist`
     - **命令设置**（执行命令）：
       - 在命令输入框中填入：`node /app/server/index.js`
   - 点击 **「确定 / 下一步」** 完成创建并启动容器！

---

### 方案 B：离线 Docker 镜像 tar 包导入法（适合电脑已开 Docker Desktop 的用户）

如果您习惯使用独立镜像包：
1. 确保电脑已启动 Docker Desktop，双击运行工程根目录下的 `打包极空间Docker镜像.bat`；
2. 脚本将自动编译镜像并导出为单一文件 `safevault-zspace.tar`；
3. 将 `safevault-zspace.tar` 上传到极空间的任意目录；
4. 打开极空间「Docker」应用 -> 进入 **「本地镜像」** -> 点击顶部 **「导入镜像」**；
5. 选择该 tar 包导入，导入后点击「创建容器」；
6. 映射端口 `8088:8088`，添加文件夹挂载（将极空间的持久化目录映射到容器内的 `/app/data`），点击启动即可！

> 若宿主机使用 `18088`，必须映射为“本地端口 `18088` → 容器端口 `8088`”；只有同时把容器环境变量 `PORT` 改为 `18088` 时，容器端口才填写 `18088`。使用代理/VPN 时还需将 `192.168.0.0/16` 设置为直连。

## 🌐 步骤二：局域网访问与极空间生成公网远程网址

容器启动成功后，您可以通过以下方式访问密码数据库：

### 1. 局域网内直接访问
在同一路由器下的手机、平板、电脑浏览器中输入：
```text
http://<你的极空间局域网IP>:8088
```
*(例如：`http://192.168.1.50:8088`)*

### 2. 极空间生成公网远程访问网址（外网随时随地访问）

极空间自带非常强大的免费远程访问服务（内置安全内网穿透），无需您拥有公网 IP 或配置繁琐的端口转发：

1. 打开电脑版「极空间」客户端；
2. 点击进入 **「系统设置」** -> **「远程访问」**（或在应用列表中打开「远程访问」）；
3. 点击 **「添加远程访问链接」**：
   - **协议**：选择 `HTTP`
   - **内网 IP**：填写 `127.0.0.1`（或者填写极空间的局域网 IP）
   - **内网端口**：填写前面配置的本地端口 `8088`
   - **备注名称**：填写 `密码数据库` 或 `SafeVault`
4. 点击保存后，极空间立即会生成一个唯一的外部安全访问链接，格式通常为：
   ```text
   https://xxxx.zspace.cn:xxxx
   ```
   *(或者极联专属网址)*
5. **在手机 4G/5G、公司外网电脑打开该网址**，即可直接安全使用您的密码数据库！

## 📲 步骤三：手机移动端配置为“沉浸式小程序”（PWA）

无需在各大应用商店下载第三方 APP，利用现代 PWA 技术，秒变原生应用体验：

1. **苹果手机（iOS / Safari 浏览器）**：
   - 使用 Safari 打开极空间生成的远程网址或内网网址；
   - 点击浏览器底部居中的 **“分享”** 图标（带有向上箭头的方框）；
   - 在菜单中向上滑动，点击 **“添加到主屏幕”**；
   - 手机桌面上将出现 **SafeVault 密码数据库** 图标。打开后无任何浏览器地址栏，全屏沉浸体验如同微信小程序或原生 App！
2. **安卓手机（Android / Chrome / Edge / 系统浏览器）**：
   - 使用浏览器打开极空间生成的网址；
   - 点击浏览器右上角菜单 `...`；
   - 选择 **“添加到主屏幕”** 或 **“安装应用”** 即可。

## 🔄 步骤四：移动端与桌面端账号数据

SafeVault 以极空间 NAS 为账号数据的唯一权威来源。账号只需在 NAS 服务上注册一次，之后所有客户端使用相同的 NAS 地址、账号和主密码登录即可。

登录成功后，客户端会在打开金库前自动下载该账号的元数据和全部加密凭据；新增、修改和删除也会自动写回 NAS。日常使用不需要再点击“同步”。“数据与历史管理”中的手动刷新、恢复性上传和旧数据合并只用于故障恢复或旧版本迁移。

极空间代理生成的临时地址可能变化，这不会改变账号归属。桌面端应优先使用稳定的局域网地址或固定反向代理域名；临时代理变化时只更换服务地址，不要重新注册账号。

为了方便后续获取程序更新，系统已内置自动化 GitHub 版本检测：

## 🛡️ 数据安全与备份建议

1. 当前运行数据库位于 `data/vault-store.json`；独立完整备份和用户历史快照位于另行挂载的 `safevault-backup/`；
2. 每次写入都会先更新独立备份再更新主库，默认轮换保留最近 30 份完整数据库；
3. 如果整个 `data/` 被误删，先停止容器并保留 `safevault-backup/`，再次启动时服务会从最新完整备份自动恢复；
4. 建议同时启用极空间回收站/快照，并定期下载 `.safevault.json` 到另一台设备。
