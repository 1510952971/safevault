# SafeVault Android 与 iOS 构建发布指南

当前全平台版本为 `1.3.0`。Web、Windows 桌面端、极空间 NAS、Android 和 iOS 共用同一套前端业务、端到端加密及自动同步代码。

## 日常同步移动端工程

修改功能后，在项目根目录执行：

```text
npm run mobile:sync
```

该命令会重新构建 Web 资源、同步 Android/iOS 版本号，并把最新资源复制到两个原生工程。`npm test` 会检查各平台版本是否与 `package.json` 一致。

## Android

工程目录为 `android`，应用 ID 为 `com.safevault.app`，最低支持 Android 7，目标 SDK 为 36。

构建环境需要 JDK 21 或更高版本。Capacitor 8 的 Android 库使用 Java 21 字节码；如果 Android Studio 或 `JAVA_HOME` 仍指向 JDK 17，Gradle 会报 `invalid source release: 21`。

1. 安装最新版 Android Studio、Android SDK 36 和 JDK 21。
2. 在 Android Studio 的 Gradle JDK 设置中确认使用 JDK 21。
3. 执行 `npm run android:sync`。
4. 执行 `npm run android:open`，在 Android Studio 中等待 Gradle 同步完成。
5. 开发测试使用 Build APK；正式发布使用 Generate Signed App Bundle，并使用长期保存的签名密钥。
6. 安装后填写极空间地址 `http://192.168.5.134:18088`，登录现有账号即可自动拉取数据。

正式签名前不要把 `.jks`、`.keystore` 或密码提交到 Git。

## iOS 和 iPadOS

工程目录为 `ios/App`，Bundle ID 为 `com.safevault.app`，最低支持 iOS 15。

1. 把仓库放到安装最新版 Xcode 的 macOS 电脑。
2. 执行 `npm install` 和 `npm run ios:sync`。
3. 执行 `npm run ios:open`。
4. 在 Xcode 的 Signing and Capabilities 中选择 Apple Developer Team，并确认 Bundle ID 唯一。
5. 使用真机测试局域网 NAS 访问；首次访问时允许“本地网络”权限。
6. 通过 Product Archive 生成归档，上传 TestFlight 或 App Store Connect。

iOS 无法在 Windows 上完成签名或生成 IPA，这是 Apple 工具链限制；本仓库中的 Xcode 工程已经准备好，可直接在 macOS 上继续。

## 极空间移动端连接要求

极空间服务的 `CORS_ORIGIN` 需要包含：

```text
https://localhost,capacitor://localhost
```

局域网可使用固定地址 `http://192.168.5.134:18088`。外网连接必须使用稳定 HTTPS 地址，不要使用极空间客户端临时生成的 `127.0.0.1` 代理端口。

## 移动端界面与主题

- 移动端顶部操作区采用带间距的紧凑图标按钮，空间不足时可左右滑动访问锁定、同步、备份、生成器和更多安全功能。
- 底部导航只保留“密码库、 安全、分类”三个入口；置顶是分类筛选，不再与密码库重复；新增凭据使用右下角浮动加号。
- 分类抽屉会显示全部凭据、核心置顶、风险审计、网站账号、工作办公、银行金融、社交媒体、游戏娱乐、其他保密和废纸篓及其数量。
- 顶部“更多 → 主题与外观”提供战术荧光、午夜黑曜、深海蓝图、极光薄荷、玫瑰雾面和纸张琥珀六种皮肤。主题只保存在当前设备，不会改动密文或同步数据。

域名失效、更换域名及 AWS/NAS 服务器迁移的无损操作步骤，已同步写入应用内“使用与运维说明手册”的“域名失效与服务器迁移”章节。核心原则是先导出 `.safevault.json`，保留旧服务器的 `data`、`backup` 和快照，确认新入口 `/api/version` 与登录、拉取、写入均正常后，最后再切换 DNS。

## 发布前检查

- 执行 `npm test` 和 `npm run mobile:sync`。
- 确认 Web、NAS、Windows、Android 和 iOS 显示相同版本。
- 在 Android 和 iPhone 真机上测试注册、登录、自动拉取、新增后上传、后台返回刷新、复制密码和自动锁定。
- 更新 NAS 部署包，使其 CORS 配置支持移动端原生来源。
- 发布前导出 `.safevault.json`，并确认 NAS 独立灾备有效。

## GitHub 版本发布包

向 GitHub 推送 `v*` 标签，或在 Actions 手动运行 `SafeVault Release`，会在同一个 GitHub Release 中生成：

- Windows x64 桌面端 ZIP；
- Android APK（Debug 签名，可直接安装测试）；
- iOS 模拟器 ZIP。未配置 Apple 签名证书，不能直接安装到真实 iPhone；
- 极空间 NAS 部署 ZIP。

正式 Android 发布前，应在 Android Studio 中使用长期保存的签名密钥生成 Release APK 或 AAB；不要把签名密钥和密码提交到仓库。
