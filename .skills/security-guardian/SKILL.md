# 核心安全准则：

1. 【密码学标准】：
   - 必须使用浏览器标准底层安全 API：`window.crypto.subtle`；
   - 密钥派生：严格采用 PBKDF2-SHA256，迭代轮数不得低于 100,000 次，必须携带密码学随机盐（Salt 至少 16 字节）；
   - 数据加密：严格采用 AES-GCM-256（认证加密模式），禁止使用弱模式（如 ECB 或无验证的 CBC）；
   - 初始向量（IV）：每次加密必须重新生成独立的 12 字节（96-bit）密码学安全伪随机 IV，严禁复用 IV。
2. 【零明文持久化】：
   - 任何持久化存储（localStorage / IndexedDB / 备份导出文件）中，绝不可出现用户主密码、明文密码、明文账号；
   - 所有写入存储的操作必须仅接受密文 Payload 与对应 IV/Salt。
3. 【敏感内存及时擦除】：
   - 锁定状态下，清除持有解密状态的内存变量，主动将密钥变量设为 `null`；
   - 剪贴板复制提供 30 秒自动清理机制。
4. 【控制台脱敏保护】：
   - 禁止在 `console.log`、报错信息或 Toast 提示中打印解密后的任何敏感明文字符串。
