# 核心防线约束准则：

1. 【代码完整性铁律】：
   - 严禁在输出中使用 "// 其余代码保持不变"、"// 省略已有逻辑" 或 "// TODO" 偷懒省略！
   - 必须提供可完整运行的代码块，或明确指出目标文件精确定位。
2. 【强类型约束】：
   - 全面禁止使用 TypeScript 的 `any` 逃避类型检查，所有实体与传输载荷必须定义 Interface；
   - 接口与状态存储必须具备严格的强类型契约。
3. 【防御性错误捕获】：
   - 所有异步 I/O 操作（Web Crypto、本地存储读写、剪贴板交互）必须包裹于 try-catch 块内；
   - 捕获异常后必须记录并返回统一格式：{ success: false, message: string }，严禁未捕获异常导致页面白屏崩溃。
4. 【旧逻辑保护】：
   - 重构前必须保持公共函数签名与数据结构类型的向后兼容；
   - 严禁擅自删除与当前需求无关的既有业务代码和注释。
