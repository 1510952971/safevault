# 视觉设计代币规范（机能战术明亮科技风）：

1. 【色彩矩阵 (Tactical Color Palette)】：
   - 背景主基调：清爽高质感微灰工业画布（`bg-[#f0f2f5]` / `bg-slate-100`），带有淡灰色工程标线与 HUD 刻度背景；
   - 品牌高能强调色 (Brand Lime)：荧光酸性黄绿/战术亮绿（`#c8f135` / `#bef264` / `#a3e635`）；
   - 战术深色块 (Tactical Dark)：机甲黑炭深灰（`#181c24` / `#222630`），用于选中导航、关键控制块；
   - 表面卡片色 (Surface Cards)：纯净白（`#ffffff`），配以微细战术边框（`border-slate-200` 或 `border-zinc-300`）；
   - 辅助文字色：高对比度纯黑主标题（`text-slate-900`）、工程编号与副标（`text-slate-500`）、战术绿点缀。
2. 【战术排版与几何元素 (Tactical Geometry)】：
   - 标题前缀标线：每个小节标题前使用鲜明荧光绿粗竖线（`| 标题`，例如 `border-l-4 border-[#c8f135] pl-2.5`）；
   - 索引编号系统：每个模块、卡片与导航均带有两位数工业编号（`01`, `02`, `03`, `#0027`）；
   - 切角/战术槽位（Slot Cards）：支持微切角卡片、直角卡片、角标 `┌ ┐ └ ┘` 装饰以及专属的“空槽位 [+]”新增卡片；
   - 战术推进按钮：左侧带斜切荧光绿色块或 `>` 箭头符号的高辨识度交互按钮。
3. 【状态指示体系】：
   - 状态圆点：`● 运行中`、`● 已加密`（荧光绿）、`● 已脱敏`（灰白）；
   - 等级与容量进度标示：如 `1 / 4` 大字号战术比率、细线条横向进度条。
4. 【移动端响应式与交互体验】：
   - 桌面端：左侧战术导航栏 + 主战术监控面板 + 右侧快速生成/升级面板；
   - 移动端：顶部战术 HUD + 横向滑动编号 Tab + 流式槽位卡片。
